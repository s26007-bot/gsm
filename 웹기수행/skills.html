HTML5 / CSS3

웹 페이지의 구조를 명확하게 나누는 시멘틱 태그를 능숙하게 다룰 수 있으며, 다양한 스타일 속성을 지정하여 완성도 높은 결과물을 만들어냅니다. 특히 transition과 keyframes 애니메이션 속성을 자유롭게 활용하여 웹 페이지 내 요소들에게 다채롭고 부드러운 시각적 효과를 부여할 수 있습니다.

Python

파이썬은 문법이 간결하고 인간의 언어와 유사하여 코드의 가독성이 높고 빠르게 프로그램을 개발할 수 있는 언어입니다. 다양한 내장 함수와 외장 라이브러리를 활용하여 데이터 분석, 웹 크롤링, 자동화 스크립트 작성 등 폭넓은 분야에 적용해 보았으며, 변수와 제어문을 활용한 논리적인 알고리즘 구현 능력을 갖추고 있습니다.

C++

C++은 객체 지향 프로그래밍과 절차적 프로그래밍을 모두 지원하며, 하드웨어를 직접 제어할 수 있을 만큼 강력하고 빠른 실행 속도를 자랑하는 언어입니다. 메모리를 직접 관리하는 포인터 개념을 깊이 있게 이해하고 있으며, 클래스와 상속, 다형성 등 객체 지향의 핵심 특징을 활용하여 효율적이고 재사용성이 높은 구조적인 코드를 작성할 수 있습니다.
